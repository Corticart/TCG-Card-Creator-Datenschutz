# TCG-Card-Creator-Datenschutz

Dieses Repository enthält die öffentlich zugängliche Datenschutzerklärung für **TCG Card Creator**.

TCG Card Creato ist eine Android-App zum Erstellen, Gestalten, Verwalten und Drucken eigener Trading Cards.

Die Datenschutzerklärung informiert über die Verarbeitung personenbezogener Daten im Zusammenhang mit der Nutzung der App, einschließlich Google AdMob, Google Play Billing und weiteren eingesetzten Funktionen.

## Datenschutzerklärung

Die aktuelle Datenschutzerklärung ist über unsere GitHub-Pages-Website abrufbar.

## Hinweis

Dieses Repository enthält ausschließlich öffentliche rechtliche Informationen. Der Quellcode von TCG Card Creato wird separat in einem privaten Repository verwaltet.
